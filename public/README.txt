=== CARA MENGUPLOAD LOGO PT. BAHTERA ADHIGUNA ===

1. Siapkan file gambar logo Anda dalam format PNG.
2. Namai file tersebut menjadi: logo.png (semua huruf kecil).
3. Upload file tersebut ke folder ini (/public/) sehingga lokasinya menjadi: /public/logo.png.
4. Ketika aplikasi dijalankan kembali, sistem akan otomatis membaca dan menampilkan file logo asli Anda!
5. Jika file belum di-upload, sistem dengan cerdas akan menampilkan logo Vector High-Fidelity buatan Mommy sebagai cadangan yang keren agar tampilan tidak rusak.
